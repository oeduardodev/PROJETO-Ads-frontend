# Trabalho local

Este é o repositório da interface. O backend guarda os documentos de arquitetura, o roteiro e `docs/implementation/PROGRESS.md` canônicos (ADR 0000). O passo 006 criou apenas o workspace; Angular entra no passo 008.

Use `corepack pnpm install` na raiz. Commits seguem `<type>(<scope>): <descrição no imperativo>` e o ID sequencial do roteiro. Execute as verificações do passo antes de cada commit. Alterações conjuntas entre frontend e backend precisam de dois SHAs registrados no progresso do backend. Não fazer push, deploy ou migração em produção sem autorização explícita.
